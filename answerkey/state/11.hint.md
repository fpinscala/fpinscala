# The Candy Machine Problem

## Machine Update Logic

First start by creating a function that takes an input (Coin/Turn),
and a machine, and returns a new machine. The function signature should be:

```Scala
def update(input: Input)(machine: Machine): Machine
```

## Introduce State Actions

Partially evaluate calls to `update` by providing input arguments.

Convert these partially evaluated functions to State Actions
by using `State.apply` or simply `State()`. The signature of the
function to proivde to the State constructor (`apply` method) is:
`Machine => (Unit, Machine)` and its implementation should use the
pre evaluated call to `update`.

You could create a wrapper around the call to the `State()` constructor
(`apply` method)

## Combine State Actions

Try to combine two consecutive state actions using the generic functions
such as `map2` which takes 2 state actions and a combination function to
combine the results and generate a new state. Remember the values are not
important in this problem, only updating and passing the state along.

## Processing a list of inputs

Now try processing the entire list of inputs first through `update`,
then converting them to state actions, and then through `sequence`

## Extracting data from state

The last part of the problem instructs us that the return type of the
value for the action should be of type `(Int, Int)` with the values
for `candy` and `coins`. In order to do this, we should find a way to
get a hold of the state (machine) so we can use `map` or `flatMap`
to describe a computation that has access to the state. Try using
the `get` function described in page 90 for this purpose.
